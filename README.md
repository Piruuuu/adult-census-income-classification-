# Adult Census Income Classification

## Project Overview

This project focuses on predicting whether an individual's annual income is above $50K or at or below $50K using demographic, educational, employment, and financial features.

The project implements a complete machine learning workflow, including data preprocessing, exploratory data analysis, feature engineering, categorical encoding, feature scaling, and Logistic Regression.

## Problem Statement

The objective is to build a binary classification model that predicts an individual's income category based on their demographic and socioeconomic characteristics.

### Target Variable

 `>50K` → 1
`<=50K` → 0

## Model

Logistic Regression was used as the classification algorithm to predict whether an individual's annual income falls above or at/below the $50K threshold.

## Dataset

The project uses the Adult Census Income dataset, which contains demographic, educational, employment, and financial attributes.
